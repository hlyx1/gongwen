- 其余 10 个组件 CSS 文件的硬编码色值不碰（勘探顺带发现已入池，另行分诊批次治理）。
- DetectionPanel.css 死规则（.detection-header/.detection-label/.detection-hint，:11-47）不删除——留待已入池的清理待办；本任务仅替换其中 2 个色值字面量。
- 阴影合成值（:456 box-shadow 的 rgba(0,0,0,0.05)）不动——属阴影族非颜色族，改值即违视觉零变化。
- public/ 下 SVG 图标（正确/警告/暂无等）内联填色不动——图片资产，非 CSS 样式值，变量规范不适用。
- statsPrinter.ts 控制台着色 hex（:28-49）不动——控制台输出非 CSS（sourceGovernance 豁免名单既有成员）。
- 不引入新依赖；不使用 chrome78 不支持的 CSS 特性——color-mix()（Chrome 111+）禁止，带透明度合成色一律独立成变量（勘探.md §2.2 差异报告末行依据）。
